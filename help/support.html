🛠️ サポート - マイクが動作しない場合

📌 ご注意
  • このページの情報は執筆時点（2025年12月）のものです。iOS/iPadOSのバージョンやブラウザのアップデートにより、設定方法や画面表示が変更される場合があります。

  • このページの方法で解決しない場合は、Apple公式サポートや他の信頼できる情報源もご参照ください。
⚠️ よくある問題

iPadやiPhoneで「音声波形ビューア」などのマイクを使用するアプリが動作しない場合、ブラウザにマイクの使用許可が与えられていない可能性があります。

📱 iPad / iPhone での解決方法（iPadOS 17以降対応）

✅ Safari の場合（推奨ブラウザ）

方法1: サイトごとの設定（簡単・推奨）

  1. アドレスバーの左端をタップ
    URLの左側にある小さなアイコン（鍵マーク🔒またはサイトアイコン）を長押しまたはタップ
  2. メニューから選択
    表示されたメニューで以下のいずれかを実行：
    • 直接「マイク」が表示されている場合 → タップして「許可」を選択
    • 「…」（3点リーダー）が表示されている場合 → タップして下にスワイプし、「マイク」を探して「許可」を選択
    • 「Webサイトの設定」が表示されている場合 → タップして「マイク」を「許可」に変更
  3. ページを再読み込み
    ページをリロードしてマイクを使用開始
💡 iPadOSバージョンによる違い
  • iPadOS 15-16: 「AA」アイコン → 「Webサイトの設定」
  • iPadOS 17以降: サイトアイコン/鍵マーク → メニュー表示（「…」または直接項目）
  • メニューの表示方法はバージョンやサイトによって異なる場合があります

方法2: Safari全体の設定

  1. 設定アプリを開く
    ホーム画面またはAppライブラリから「⚙️ 設定」をタップ
  2. Safari を探す
    • iPadOS 17以降: 左側メニューから「アプリ」→「Safari」を選択（青いコンパスのアイコン）
    • iPadOS 16以前: 下にスクロールして「Safari」をタップ
  3. マイクの設定を変更
    下の方にある「マイク」をタップし、以下から選択：
    • 「確認」（推奨）: サイトごとに毎回確認
    • 「許可」: すべてのサイトで自動許可
  4. Safariに戻る
    ページをリロードし、許可のダイアログで「許可」をタップ
✅ Chrome の場合（最新iPadOS）
  1. 設定アプリを開く
    ホーム画面から「⚙️ 設定」をタップ
  2. 「アプリ」を選択
    左側のメニューから「アプリ」をタップ（最新iPadOSで追加された項目）
  3. Chrome を探す
    アプリ一覧から「Chrome」をタップ（赤・黄・緑・青の丸いアイコン）
  4. マイクをオンにする
    「マイク」のスイッチをオン（緑色）にする
  5. Chromeでページを開く
    Chromeアプリでページをリロードし、マイクへのアクセスを許可
💡 重要なヒント
  • 最新のiPadOS（17以降）では、設定方法が大きく変更されています
  • Safariのアドレスバーから直接サイトごとの許可を管理できます（方法1が最も簡単）
  • プライベートブラウズモードでは、タブを閉じると設定がリセットされます
  • 設定変更後は必ずページをリロード（再読み込み）してください
  • iPhoneでは左側メニューがなく、縦スクロールで設定項目を探します

💻 パソコン（Mac/Windows）での解決方法

✅ ブラウザ上での許可
  1. アドレスバーのアイコンをクリック
    URLの左側にある鍵マーク🔒またはカメラアイコンをクリック
  2. マイクの設定を変更
    「マイク」の項目を「許可」に変更
  3. ページを再読み込み
    ページをリロードして、マイクへのアクセスを許可

🔍 それでも解決しない場合

📌 確認事項
  • HTTPSで接続しているか: https:// で始まるURLを使用していますか？
  • プライベートブラウズモード: シークレットモードやプライベートブラウズでは設定がリセットされます
  • ブラウザのバージョン: 最新版のブラウザを使用していますか？
  • デバイスのマイク: 他のアプリ（ボイスメモなど）でマイクが動作しますか？
⚠️ 重要な注意事項
  • file:// で始まるローカルファイルでは、セキュリティ上の理由でマイクは使用できません
  • Webサーバー経由（http://localhost または https://）でアクセスする必要があります
